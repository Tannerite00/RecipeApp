# RecipeHub

This is a Whole-Food Plant-Based Vegan Recipe, Meal Plan, and Grocery list App. 

# Features

Create an account and start planning your weeks!

Over 1650+ Whole-Food Plant-Based Vegan Recipes to choose from! 

No fluff! Each recipe gets straight to the point, no paragraphs of story, just detailed isntructions!

Leave comments and rate each recipe you use to let other users know how good it was! 

In your account profile, you can see and access every recipe you have rated or commented on.
 
There is a recipe search page where you can filter by recipe type, or start searching by ingredients if you are trying to make something with what you have at home.

Once you have some recipe's added you can check if they are in the correct spot on the Meal Plan Page. 

After you have added your recipes to the days you'd like to make them, they are automatically added to the Grocery List page and combined with other like ingredients. 

The Grocery List Page features a progress bar, which will turn blue and congratulate you with confetti once you have checked off all of your items. Never miss an item on the list again!


## Offline support

The app caches recipes and ratings in your browser the first time they load. 

If you reopen the app without internet, the cached data is used so browsing still works. 

Any ratings you leave while offline are queued locally and synced automatically the next time you have connectivity.
